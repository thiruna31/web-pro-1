# FlavorCanvas — CSC 6370 Project 1

## About the Project

FlavorCanvas is a recipe website created for CSC 6370 Project 1. The goal of the project is to make it easy for users to explore recipes, find meal ideas, and learn more about different dishes.

The website is built mainly with HTML5 and CSS3. We focused on keeping the pages organized, making the design consistent, and ensuring the website works on different screen sizes.

## Pages

- **Home (`index.html`)** — Introduces FlavorCanvas and highlights different meal ideas.
- **Recipe Collection (`recipes.html`)** — Displays the available recipes.
- **Recipe Details (`recipe-details.html`)** — Provides a page for viewing recipe information.
- **About & Contact (`about.html`)** — Shares information about the project and provides contact details.
- **Team (`team.html`)** — Introduces the people working on the project.

Individual recipe pages are also included for dishes such as avocado toast, chicken stir fry, chocolate pancakes, grilled salmon, and tomato soup.

## Project Features

The project follows the Recipe Studio topic and includes the Story Pack extension.

Some of the main features are:

- Recipe cards with food images and links to recipe pages.
- A consistent layout and navigation across the website.
- Responsive styling for desktop, tablet, and mobile screens.
- CSS Grid and Flexbox for arranging page content.
- Hover effects, transitions, and animations.
- Keyboard focus styling and reduced-motion support.
- A Suggested for You section demonstrating a recommendation interface.
- A Cooking Assistant interface concept.

The recommendation and cooking assistant sections are design demonstrations rather than fully automated services.

## Running the Website

Open `index.html` in a web browser to view the website. You can also use the Live Server extension in Visual Studio Code to preview the pages while working on them.

## Images and Design

The project uses food images throughout the homepage, recipe collection, and recipe pages. The original design direction was based on the approved project proposal, which is available in `docs/approved-design-board.jpg`.

The image assets were updated to improve their appearance on the website while keeping the overall design consistent with the proposal.

## Development and Testing

During development, we worked on the page layouts, navigation, styling, and presentation of the recipe content.

Before submission, the website should be checked for:

- Working navigation and recipe links.
- Images loading correctly.
- Layouts on desktop, tablet, and mobile.
- Keyboard navigation and visible focus.
- Reduced-motion support.
- Complete project documentation and development evidence.

The `docs/` folder contains project documentation and design materials. The development journal and checklist can be used to record progress and verify the remaining requirements.
